# Dados recuperáveis / reimportáveis

Nenhum dataset jurídico perdido foi fabricado durante a reconstrução do repositório.

Arquivos agregados de DataJud, filtros TPU, snapshots JEC e manifestos de importação devem ser restaurados apenas a partir de fonte confiável, com proveniência e metodologia registradas. Dados brutos pessoais não devem ser versionados aqui.
